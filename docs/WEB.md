# 2MP — архитектура для веб-интерфейса

Документ для того, кто делает или переделывает сайт. Бэкенд готов и работает; сайт — одна страница, которую отдаёт тот же сервис.

## 1. Общая схема

```
Браузер (сайт)                         Жюри (скрипт)
     │  /web/*  (без ключа, с лимитами)      │  /api/v1/*  (заголовок X-API-Key)
     └───────────────┬──────────────────────┘
                     ▼
        FastAPI  app.py  — порт 8000, публично: https://hr73swuj49slfk-8000.proxy.runpod.net
        ├─ GET  /                 → static/index.html  (сам сайт)
        ├─ GET  /static/*         → static/ (демо, шрифты, ваши файлы)
        ├─ очередь задач (жюри всегда раньше сайта)
        ▼
        worker.py → pipeline.py  (кадры → Qwen3-VL + YOLOX/RTMPose → нарушения → норма НБРК)
                     ▼
        vLLM (Qwen3-VL) — 127.0.0.1:18001, снаружи недоступен
```

- Сайт = файл `static/index.html` (HTML + CSS + JS в одном файле, без сборки). Сервис отдаёт его по `/`.
- Отдельный фронтенд на другом домене **не заработает**: CORS не включён, а ключ API в браузер класть нельзя. Делайте страницу в `static/` (можно несколько файлов: `static/app.js`, `static/style.css` — они доступны по `/static/...`).

## 2. Ограничения браузера (CSP — их задаёт сервер)

```
default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src 'self' https://fonts.gstatic.com; img-src 'self' data: blob:; media-src 'self' blob:; connect-src 'self';
frame-ancestors 'none'
```
- **Скрипты только свои** (inline или из `/static/`). CDN (unpkg, jsdelivr, cdnjs) заблокированы — библиотеки класть файлом в `static/`.
- Запросы (`fetch`) — только к своему серверу (относительные пути `/web/...`).
- Картинки: свои, `data:` (base64 кадров) и `blob:`. Видео: своё и `blob:` (`URL.createObjectURL(file)`).
- Шрифт: `/static/fonts/onest.css` (локальная копия Onest; Google Fonts разрешён, но для работы без интернета лучше локально).
- Сайт нельзя встроить в `<iframe>` на другом сайте.

## 3. Эндпоинты для сайта (без ключа)

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/web/analyze` | загрузить видео: `multipart/form-data`, поле `file` → `{"job_id": "...", "status": "processing"}` |
| GET | `/web/jobs/{job_id}` | статус и результат (полный, см. §5) |
| POST | `/web/jobs/{job_id}/review` | решение проверяющего: JSON `{"i": 0, "decision": "confirmed" \| "rejected", "note": "текст ≤500"}` → `{"ok": true}` |
| GET | `/results/{job_id}_annotated.mp4` | видео с разметкой людей (появляется позже результата, см. `annotated_status`) |
| GET | `/health` | `{"ok", "model", "profile", "offline", "pose", "queue", ...}` — для «шапки» (модель, без интернета) |
| GET | `/static/demo/result.json`, `/static/demo/demo.mp4` | готовый пример результата («Открыть пример проверки») |

Ошибки (всегда JSON `{"error": "понятный текст по-русски"}` — показывать пользователю как есть):
- `400` — не видео / пустой файл / нет поля `file` / видео длиннее 15 мин;
- `413` — файл больше 200 МБ; `415` — не тот формат (нужно `.mov`, `.mp4`, `.m4v`, `.avi`, `.mkv`);
- `429` — лимит сайта: не больше 3 загрузок в очереди и 10 в час с одного адреса (жюри важнее);
- `404` — задача не найдена (или это задача жюри — сайт их не видит).

Задачи сайта и жюри разделены: по `/web/jobs/{id}` нельзя открыть задачу, загруженную через API, и наоборот.
`job_id` — 24 hex-символа.

## 4. Сценарий страницы

1. Пользователь выбирает/перетаскивает файл → `POST /web/analyze`.
2. Опрос `GET /web/jobs/{id}` каждые 1–2 с, пока `status == "processing"`; показывать `progress` (0–100) и `stage` (готовый текст: «Поиск рабочего места кассира», «Просмотр записи: фрагмент 3 из 12», «Перепроверка подозрительных моментов: 2», «Подготовка кадров-доказательств и норм»…). Обычно 30 с – 3 мин.
3. `status == "done"` → рисуем результат; `status == "failed"` → показать `error`.
4. Видео для плеера — **локальное**: `URL.createObjectURL(file)`. Сервер исходное видео удаляет сразу после анализа и не отдаёт.
5. История проверок — в `localStorage` браузера (`[{id, name, status, verdict, n}]`); сервер список задач не отдаёт. Результаты хранятся 72 ч.
6. Демо: `fetch('/static/demo/result.json')` + видео `/static/demo/demo.mp4`.

Тексты вердикта по ТЗ (дословно): **«Нарушение не обнаружено»** / **«Обнаружены признаки возможных нарушений»**.

## 5. Результат `GET /web/jobs/{id}` (status = done)

Координаты рамок — **0..1000 от ширины/высоты кадра** (не пиксели): `x_px = b[0] / 1000 * videoWidth`.
Время — секунды от начала видео.

```jsonc
{
  "job_id": "3f2a…", "status": "done", "progress": 100, "stage": "Готово",
  "name": "kassa_01.mov",                 // имя загруженного файла
  "verdict": "violation",                 // или "no_violation"
  "duration": 17.07,                      // длительность видео, с
  "violations": [{
    "type": "Сокрытие части принятых наличных",   // название типа (по-русски)
    "timecode_sec": 13.7,
    "description": "Что видно… Признак возможного нарушения: … Норма: …",
    "evidence_frames": [                   // 1–3 кадра: ключевой и ±1.5 с
      {"timestamp_sec": 12.2, "image_base64": "/9j/4AAQ…"}   // JPEG → src="data:image/jpeg;base64,…"
    ],
    "key_frame_sec": 13.71,                // какой из evidence_frames ключевой
    "bbox": [288, 444, 499, 602],          // рамка объекта на ключевом кадре (0..1000) или null — для рамки и «лупы»
    "confidence": 0.85,                    // 0..1
    "verification": "confirmed",           // confirmed (Qwen подтвердил) | rule | scan | unverified
    "object_type": "banknote",             // banknote | card | phone | paper | unknown
    "rule": {"id": "CASH_CONCEALMENT", "document": "Правила … № 231 …", "point": "п. 20, п. 14", "text": "формулировка нормы"},
    "legal_reference": {                   // дословная цитата из текста Правил (может быть null — тогда показывать rule)
      "source": "adilet.zan.kz", "document": "Правила … № 231", "article": "п. 20",
      "quote": "Наличные деньги принимаются и пересчитываются кассовым работником в присутствии клиента…",
      "url": "https://adilet.zan.kz/rus/docs/V1900019680", "relevance": "", "confidence": "high"
    },
    "legal_confidence": "high"
  }],
  "scores":  [{"t": 2.0, "s": 0.03}, …],   // «кривая подозрительности»: s 0..1 по времени
  "thumbs":  [{"t": 0.5, "b64": "…"}, …],  // 16 миниатюр по длине видео (лента кадров), JPEG base64
  "tracks":  [{"t": 0.0,                    // рамки людей/предметов по времени (≈4–5 раз в секунду) — оверлей на видео
               "p": [{"id": 3, "r": "cashier", "b": [x1,y1,x2,y2]}],   // r: cashier | client | collector | unknown
               "o": [{"c": "phone", "id": 10, "b": [...], "s": 0.8}]}],  // предметы (если есть)
  "zones": {…}, "zone": [x1,y1,x2,y2] | null,   // зоны кассы (0..1000), необязательно для UI
  "reviews": {"0": {"decision": "confirmed", "note": "…"}},   // решения проверяющего по индексу нарушения
  "annotated_status": "rendering" | "ready" | "failed" | "off",
  "annotated_video_url": "/results/3f2a…_annotated.mp4" | null,   // когда ready
  "elapsed_sec": 48.2, "model": "qwen"
  // служебное, для UI не нужно: rule_events, roles, cands_debug, windows, candidates
}
```

Оверлей людей: найти в `tracks` ближайший кадр по `video.currentTime` (интерполяция между соседними `t` по `id`), нарисовать рамки на `<canvas>` поверх `<video>` с учётом `object-fit` (letterbox). Цвета в текущем сайте: кассир — бирюзовый, клиент — жёлтый, кассир в момент нарушения (±2 с от `timecode_sec`) — красный.

## 6. Что обязательно по ТЗ показать пользователю

Для каждого нарушения: **тип**, **таймкод**, **кадр(ы)-доказательство**, **что видно** (начало `description`), **норма: документ + пункт** (`legal_reference` или `rule`). Плюс вердикт и статус обработки. Остальное (кривая, оверлей, лупа, решения проверяющего, акт) — плюс к оценке «удобство интерфейса».

## 7. Где что в репозитории

```
app.py          эндпоинты, лимиты, CSP, очередь
worker.py       обработка задачи, видео с разметкой
pipeline.py     анализ видео (результат §5)
static/index.html   текущий сайт (можно заменить)
static/demo/    пример результата
docs/SUBMISSION.md  описание решения для жюри
```

Проверить свою страницу локально без GPU: `VLM_MOCK=1 API_KEY=test-key-0123456789 python3 -m uvicorn app:app --port 8000` → `http://localhost:8000` (анализ вернёт пустой результат, демо работает).

# Сайт 2MP — структура

static/
├── index.html      — весь сайт: главный экран + раздел «Анализ видео» (одна страница)
├── cube-loop.js    — живой 3D-куб 2MP (мышь, перетаскивание, клик), темы data-theme="violet" (на сайте) и "teal"
├── demo/
│   ├── demo.mp4    — видео для кнопки «Открыть пример проверки»
│   └── result.json — готовый результат для примера
└── README_SITE.md

Экраны (переключаются без перезагрузки):
- /            — главный экран: куб по центру, заголовок, кнопка «Анализ видео →»
- /#analyze    — анализ: загрузка .mov/.mp4, статус, вердикт, видео с рамками, карточки нарушений

Страница обращается к серверу (app.py):
- GET  /health             — статус модели (для чипа «Локальный анализ»)
- POST /web/analyze        — загрузка видео → job_id
- GET  /web/jobs/{id}      — статус и результат
- POST /web/jobs/{id}/review — решение проверяющего
API для жюри (/api/v1/...) не меняется.

Установка: файлы уже в репозитории; на сервере `git pull` — перезапуск не нужен (static/ раздаётся с диска).
Отдельный сервер для сайта не нужен — его раздаёт тот же FastAPI.
